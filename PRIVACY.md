# ViceClips Uploader – Privacy Policy

ViceClips Uploader is a personal tool used only by its owner to publish short gaming clips to the owner's own YouTube channels through the YouTube Data API.

- It only requests permission to upload videos and read basic channel info of the owner's channels.
- No data from other users is collected, stored, sold or shared.
- Authorization tokens are stored privately as encrypted GitHub Actions secrets and can be revoked at any time at https://myaccount.google.com/permissions.

Contact: through the GitHub repository issues.
